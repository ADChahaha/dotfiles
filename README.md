# 一些配置文件

## Requirements
zsh

powerlevel10k

wezterm

## USAGE
```bash
git clone git@github.com:ADChahaha/dotfiles.git ~/dotfiles
# 配置zsh
ln -s ~/dotfiles/.zshrc ~/.zshrc
# 配置powerlevel10k
ln -s ~/dotfiles/.p10k.zsh ~/.p10k.zsh
# 配置wezterm
ln -s ~/dotfiles/wezterm ~/.config/wezterm
```
